## 代码与验证

本次保存 Responses API 支持、只接收完整响应的解析逻辑，以及逐轮子代理文件交接驱动。后者复用原提示词、候选修复与三场景验证，采用本地合成 Responses 封装，不发起外部 HTTP 请求，也不自行创建子代理。每轮需要当前聊天显式调度和确认输出。

子代理未设置 token 上限覆盖，但实际 token 用量未知；不能称为无限推理，温度也无法通过该工具设置。原始参考解和停止阈值均未给优化子代理。

当前求解器及测试文件与通过 **145 项回归测试**的快照逐字节一致。最新实验审计包含 **61 份可行调度**（含复用 SA 对照），最大物理残差 **6.82e-13 MW**。早先中止的 Farluna 实验独立审计了 **117 份可行调度**。单次 Astra 的成功验证使用 12 次连续调度求解；首次验证封装故障前另执行 3 次，累计为 15 次，没有额外模型尝试。

## 归档与复核

每个子目录提供可直接阅读的报告、汇总与审计，以及 `reproducibility.zip`：精确源码、原始事件、冻结模型输入和输出、候选、验证记录及执行脚本均保留。`manifest.json` 记录源文件 SHA-256 和压缩包哈希；`SHA256SUMS` 覆盖这里发布的全部文件。归档前逐文件扫描排除了本地 API 密钥，`.env` 未提交。

阅读报告不需要运行任何实验。在新的检出目录中，可将各压缩包解压到它对应的 `results/<同名目录>/` 以检查原始证据。压缩包内的历史进程 ID 和进程控制脚本仅保留执行出处；不要将它们作为当前进程操作目标。主报告已反映停止时状态，无需运行任何监督或模型脚本。

历史提交和版本标签保留在 Git 中；本版把原有串行实验分支上的提交统一纳入 `main`。
