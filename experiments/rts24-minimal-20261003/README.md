## 固定协议

- A：原固定种子 SA；B：第 k 次 SA 种子为运行种子 + k - 1。
- C：LLM-only；D：停滞三轮后连续三次 LLM；E：同触发方式，用规则启发式替代 LLM。
- 运行种子 7、17、27；每次从初始化开始计时，预算 1800 秒，无轮数和目标成本提前停止。
- C、D 每次最多三次 Astra/max 新子代理会话，每次最多四个提案；首批最多 18 次模型调用。
- E 默认总共三轮建议，每轮扫描按收益排序的整段关机和两端修剪操作，修复/去重后至多四个不同候选。
- C 额度耗尽即结束；A、B、D、E 继续 SA 至截止。所有候选接受相同物理、成本复核。
- Gurobi 参考单独求一次：单线程、600 秒、MIPGap 1e-6，独立固定调度复核；不进入搜索输入。
- 失败与等待计入预算；截止后结果不计分，正在执行的 SDK 调用允许有单列的超时开销。

规则使用 LLM 输入中相同的前 60 项关机收益表。表外小时燃料变化按零估计，固定成本已知；计入启动/停机成本变化。为获取四个不同候选所尝试的修复、重复和失败全部记入统计和时间。
