# SA＋Astra 参考差试验：按用户要求在第 16 轮停止

本次完成 16 轮固定 SA→LLM 交替，正常处理第 16 次 Astra 调用的所有候选后，按用户新指令停止。原定参考差严格低于 0.1% 的目标未达到；程序状态为 CANCELLED，不能标为 TARGET_REACHED。

## 主要结果

| 方法 | 计算次数 | 最佳可行成本 | 相对 Gurobi 参考成本差 |
|---|---|---:|---:|
| Gurobi 完整模型，经固定开停机连续复核 | 独立参考 | 571,014.051896 | — |
| 纯 SA，同调用数前缀 | 16 次 SA | 614,177.849905 | 7.559148% |
| 纯 SA，完整对照 | 50 次 SA | 612,502.196470 | 7.265696% |
| SA＋Astra | 16 次 SA＋16 次 LLM | **572,242.837016** | **0.215193%** |

最佳解在第 16 轮获得，原始提案无需修复。与参考成本相差 1,228.785120；240 个开停机位中有 7 位与参考方案不同。

同调用数比较并非同总计算预算比较。纯 SA 与混合方法使用同一数据、源文件、SA 参数及 Gurobi 全局 Seed=7/Threads=1。LLM 为全新 gpt-6-astra/max 子代理，串行执行；提示词、候选反馈和 SA 参数在此次正式运行内未调整。参考成本和参考方案不进入优化 JSON。

## 差距与数值验证

参考下界为 571,014.051080。在模型和数值容差下，借助此独立下界，最终方案相对真实最优成本的误差上界约 0.215194%。

算法自身可靠下界为 564,696.768642，按 (UB−LB)/UB 计算的认证 gap 为 1.318683%。这与相对参考可行成本的 0.215193% 是不同指标。

原始 Gurobi MIQP 出力在低负荷场景有约 1.21e-5 MW 的最小出力残差，略超项目既有 1e-5 MW 校验阈值。保持其开停机方案不变，使用与候选相同的连续子问题重算出力后通过校验；成本仅增加约 0.000016。原始结果、复核结果与下界均保留，没有放宽校验标准。

混合轨迹全部 56 份新可行调度重新通过独立物理与成本核验，最大物理残差 1.14e-12 MW，最大成本残差 1.16e-09。纯 SA 对照另有 38 份可行调度通过复核。

## 候选、耗时与限制

16 次调用共返回 63 个原始提案：51 个被解析器接受，9 个重复，3 个矩阵格式不合法；39 个提案被修复器改变。最终发生 51 次新的 LLM 候选完整评估；缓存结果不会算作新的求解或新的改善。

混合运行记录 237 次连续调度调用，端到端时间 5323.85 秒（88.73 分钟），其中程序等待代理交接 4921.33 秒。Gurobi 完整参考求解 9.94 秒，另有固定调度复核；纯 SA 的 16 次前缀为 123.52 秒，50 次总计 817.29 秒。

第 7 轮包含用户中断后恢复的等待：候选文件写完到回执发布约 823.49 秒。上述时间包含聊天调度和等待，不能称为纯模型推理时间，也不能据此宣称速度优势。实际模型 token 数不可得。没有外部 LLM HTTP 请求或量子真机调用。

本次是单算例、单种子，并在用户要求下修改了停止规则；不能据此推断跨实例的稳定性。保留所有未改善轮次、重复和无效提案。
