# RTS-24 随机 SUC Gap 补足协议

用户根据首轮实测（完整日调度占九成以上耗时）批准 v2：`defer_full_recovery=True` 将完整日评估
延至每个块求解结束后的前16个候选池，局部调度、割及认证保持原样。此选项默认 False；正式三臂
统一开启，小算例纯 SA 基线关闭。`--prior-attempt` 保留旧尝试并扣除其实际墙钟时间；随机参考仅在
输入和完整模型字节一致、再次通过物理校验时复用。旧源码、日志、参考和中断记录随最终归档保存。

目标是三个种子 7／100007／200007 的 600 秒确认运行均满足
`paper_gap=(R-L)/R <= 0.01`，挑战线为 0.005。R 为独立参考可行成本，
L 为认证下界；可行成本高于参考的比例及原问题上下界 gap 分开报告。
参考仅供报告及筛查选块，不进入搜索输入、候选生成、乘子更新或算法停止条件。

SA 参数、输入场景、概率、备用及成本保持原样。正式运行外层 40 次、每块内层 200 次、
容差 1e-4；三机组兼容运行沿用 20／60 次。全部串行、单线程，Gurobi 种子固定为 7。

| 阶段 | 内容 | 预算秒 |
|---|---|---:|
| 参考 | 随机参考 600，历史输入及确定性参考复核 120 | 720 |
| 兼容 | n3-det、1h，纯 SA／混合各三种子×60 | 360 |
| 确定性 | n10-det／n32-det，1h 经典分解各120 | 240 |
| 筛查 | n32-stoch，1／2／3／5h 经典分解各300 | 1200 |
| 经典确认 | 选定分块，经典分解600 | 600 |
| 对照 | 纯 SA／混合各三种子，经典一次，各300 | 2100 |
| 最终确认 | 混合三个种子各600 | 1800 |
| 审计 | 独立物理／成本复核及报告 | 180 |
| 合计 | 包括启动、初始化及求解；开发与回归另计 | 7200 |

阶段使用累计墙钟截止时间，每个运行仍使用自己的固定预算；提前结束释放的时间覆盖控制和
审计开销，不增加试验数或单次求解预算。确认槽位被总截止时间缩短时不得判为最终达标。

纯 SA 禁用经典候选。经典臂关闭 SA，每次内层调用经典主问题。
混合臂连续三次内层上界改善不超过 1e-5 后注入经典点，每次尝试后重置停滞计数。
经典点必须经离散、局部调度及全日恢复验证；它不替代认证器的 ObjBound，也不作为 SA 初值。
来源 native_master／mixed_native 贯穿局部池、跨轮复用及拼接；改进金额按完整方案来源归类，
不表示独立的因果贡献。不同乘子下的块界不能直接相加。

筛查排除数值审计失败的配置。有效协调上界低于 0.99R 的配置标为当前分块目标不可达；
超时及内层上限只表示未判定。其余配置按末尾认证下界最大选择，差不超过 1e-5 时选更短分块。
后续分块固定。四种分块均不可用时停止正式运行；随机参考未认证或小算例兼容失败也停止。

运行前冻结源码、测试、输入及历史原始参考，保存 SHA256、依赖和完整配置。
事件以单调时钟计分；每次可行改进及下界更新原子保存检查点。截止后的完整事件只留档。
最终三次运行都需有效认证下界、有效参考和独立通过校验的完整方案；DUAL_CONVERGED 单列。

输出包括 manifest.json、selection.json、每次 config.json、events.jsonl、checkpoint.json、
result.json、state.json、summary.json、audit.json、runs.csv、blocks.csv、curves.csv、
下界与论文 gap 曲线、中文 README 和 SHA256SUMS.txt。
使用相同冻结代码运行 `--report-only` 重建数值报告；历史结果和失败尝试不覆盖。
